## [1.0.0] - 2026-10-03

### Added

- Single and multi file upload
- Drag and drop upload
- Clipboard and text sharing
- Single file download
- Download all files as ZIP
- QR code to open the UI from any device
- Transfer progress bar
- Camera capture upload
- PIN protection
- Dark mode
- File expiry and auto cleanup
- Live file list over SSE
- File preview for images, text, PDF, video, and audio
- Peer clipboard sync
- Transfer speed meter and ETA
- File rename before download
- Session rooms
- Device names and presence
- Send-to-device push
- File notes and annotations
- Network info panel
- CLI flags and config file
- Graceful shutdown and cleanup
- Security hardening
- Toast notifications
- Keyboard shortcuts
- Drag reorder of the file queue
- File type icons and MIME detection
- Copy link button
- Accessibility (WCAG 2.1 AA)
- REST API for uploads, downloads, rooms, devices, and admin operations
- SSE events API for real-time file list, presence, clipboard, and progress updates
- Test suite (Vitest) with enforced coverage thresholds (>= 80% statements, lines, and functions; >= 75% branches)
- CI workflows (GitHub Actions) running lint and tests on Node.js 18, 20, and 22
- Docker image support (Dockerfile and docker-compose.yml)
- Documentation set (README, CONTRIBUTING, CODE_OF_CONDUCT, CHANGELOG, and docs/)

See [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).
